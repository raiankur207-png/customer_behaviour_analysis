# customer_behaviour_analysis
data analytics project on customer behavior analysis using python, Mysql and power bi
📊 Data Analytics Project
🔹 Overview

This project demonstrates an end-to-end Data Analytics workflow, starting from dataset loading and data cleaning to SQL analysis, Power BI visualization, reporting, and presentation.

The goal is to transform raw data into meaningful insights and interactive dashboards that can support data-driven decision-making.

📁 Dataset

The project uses a structured dataset containing relevant business information.

The dataset was:

Loaded and analyzed using Python
Cleaned and prepared for analysis
Stored/processed using SQL
Used to create visualizations and dashboards in Power BI

🔄 Project Steps
1. Data Loading
Imported the dataset into Python using Pandas.
Checked the dataset structure, columns, data types, and basic statistics.
2. Exploratory Data Analysis (EDA)
Analyzed distributions and patterns in the data.
Identified important trends and relationships.
Created charts and visualizations using Matplotlib and Seaborn.
3. Data Cleaning
Handled missing values.
Removed duplicate records.
Corrected data types.
Identified and handled inconsistencies and outliers where required.
4. SQL Analysis
Imported the cleaned data into the SQL database.
Created SQL queries to analyze business-related questions.
Used:
SELECT
WHERE
GROUP BY
ORDER BY
JOIN
Aggregate functions
Subqueries/CTEs where required
5. Power BI Dashboard
Connected the cleaned dataset to Power BI.
Created interactive charts, KPIs, filters, and slicers.
Designed a user-friendly dashboard to highlight key insights.
6. Report

Created a project report covering:

Business problem
Dataset description
Data cleaning
EDA
SQL analysis
Dashboard insights
Key findings
Conclusion
7. Presentation

Created a professional project presentation using Gamma, summarizing the project workflow, analysis, dashboard, and results.
